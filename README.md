# Ultimate Anti-AI UI Slop

Профессиональный инженерный фреймворк и системный скилл для проектирования веб-сайтов и пользовательских интерфейсов высшего класса, полностью очищенных от признаков 'нейросетевого мусора' (AI UI Slop).

Разработан на базе дизайн-систем и исходных кодов мировых лидеров индустрии:
- **Google DeepMind**: научный редакционный стиль, академическая типографика (Serif + Sans), обсидиановые фоны, строгие разделители.
- **Apple**: монументальный масштаб продукта, кинематографические отступы (120-180px), физичные материалы (сатинированный металл, матовое стекло), монохромная база с одним функциональным акцентом.
- **Cloudflare**: высокая информационная плотность, живая телеметрия, интерактивные графики latency/DDoS, асимметричные Bento-сетки.
- **GitHub**: инструментарий разработчика, терминальные интерфейсы, блоки реального кода, CI/CD индикаторы, палитра Primer Dark.
- **Linear & Stripe**: микро-бордеры с направленным светом, клавиатурные подсказки (`<kbd>⌘K</kbd>`), многоуровневая иерархия поверхностей.

## The Ban List: Краткий свод запретов

1. Запрещены фиолетово-индиговые градиенты текста (`bg-clip-text text-transparent`) и заголовков.
2. Запрещены размытые неоновые пятна (`filter: blur(100px)`).
3. Запрещен шаблон '3 одинаковые карточки фич' с иконками в кружочках.
4. Запрещен синтетический маркетинговый копирайтинг ('Supercharge', 'Seamless synergy', 'Next-gen').
5. Запрещены летающие абстрактные 3D-сферы и кубы без функционального назначения.
6. Запрещены круглые кнопки-таблетки с размытыми тенями.
7. Запрещены декоративные эмодзи в разметке и статусах.
8. Запрещен голый Inter без настройки трекинга и оптической компенсации.

## Применение

Для использования скилла в агентных средах и LLM укажите ссылку на `SKILL.md` или импортируйте его как системную инструкцию перед генерацией веб-интерфейсов.
Любая модель, следующая протоколу, обязана выбрать один из 5 архетипов и пройти 10-пунктовую проверку Quality Gate перед выводом кода.
