# Anti-AI UI Slop (v2.0 Masterpiece Edition)

Универсальный инженерный фреймворк и системный навык (Agent Skill) для проектирования и верстки веб-интерфейсов высшего мирового уровня, полностью очищенных от признаков «нейросетевого мусора» (AI UI Slop).

Разработан на базе детального аудита исходных кодов, дизайн-систем и лучших практик мировых технологических лидеров:
- **Google DeepMind**: академический редакционный стиль, строгая антиква (Serif + Sans), обсидиановые фоны, линейки hairline, формальные математические верификации.
- **Apple**: монументальный масштаб продукта, кинематографические отступы (120–180px), физичные материалы (сатинированный титан, матовое стекло с сатурацией 180%), монохромная база с одним функциональным акцентом.
- **Cloudflare**: экстремальная плотность данных, живая телеметрия, интерактивные гистограммы задержек P95, Anycast-маршрутизация, асимметричные Bento-сетки.
- **GitHub Primer**: инструментарий разработчика, терминальные интерфейсы с копированием команд в один клик, визуализация CI/CD-пайплайнов и коммит-графов.
- **Linear**: субпиксельные микро-бордеры с направленным светом, клавиатурное управление (`<kbd>⌘K</kbd>`), zero-latency отклик.
- **Vercel (Geist)**: монохроматическая прецизионность, шрифт Geist, техника shadow-as-border, карточки развертывания со статусами веток.
- **Teenage Engineering**: аппаратный функциональный брутализм, ограничение 5 физическими цветами, исключительно моноширинная типографика, точечные матрицы и механические переключатели.
- **Stripe**: кинетическая плавность микро-взаимодействий, интерактивный биллинг, гармоничные двухслойные тени и многослойные поверхности.

## The 10 Core Bans (Краткий кодекс запретов)

1. **Никаких радужно-фиолетовых градиентов текста** (`bg-clip-text text-transparent`). Заголовок всегда сплошной, контрастный и четкий.
2. **Никаких размытых неоновых шаров** (`blur-[100px]`). Структура формируется разделителями 1px hairline и направленными масками.
3. **Никаких одинаковых троек карточек** (`grid-cols-3` с иконкой по центру). Только асимметричные Bento-сетки с реальным функционалом.
4. **Никакого синтетического булшит-маркетинга** («Supercharge», «Seamless synergy», «Next-gen»). Только конкретные инженерные термины и цифры.
5. **Никаких декоративных эмодзи** (🚀, 🔥, 💡) в разметке и заголовках.
6. **Никакого голого шрифта Inter** без компенсации отрицательного трекинга на крупных кеглях.
7. **Никаких прыгающих карточек при наведении** (`translateY(-10px)`). Изменяется только цвет микро-границы и подложка.
8. **Никакого бежево-латунного дефолта** для премиальных сайтов. Ротация палитр обязательна.
9. **Никаких затянутых 800ms-анимаций появления**, блокирующих чтение. Переходы длятся 120–220ms.
10. **Никаких плейсхолдеров вместо label** в формах и неконтрастного текста кнопок.

## Как использовать

### В агентных средах и LLM (Claude, Cursor, OpenClaw, Roo Code, Gemini)
Импортируйте `SKILL.md` в качестве системного контекста или добавьте скилл в библиотеку навыков:
```bash
npx skills add <путь к репозиторию> --skill anti-ai-ui-slop
```
При любой задаче на верстку модель обязана:
1. Выдать строчку **Design Read** с анализом задачи и калибровкой регуляторов (V / M / D).
2. Выбрать один из 8 архетипов из `archetypes.md`.
3. Подключить соответствующие токены из `tokens.css`.
4. Пройти 15 пунктов **Quality Gate** перед выдачей готового кода.
