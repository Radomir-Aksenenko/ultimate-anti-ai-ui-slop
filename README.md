## 🎨 Visual Foundations & The Golden Rules

| Category | High-End Standard (v13.0) ✅ | Forbidden AI Clichés 🚫 |
| :--- | :--- | :--- |
| **Geometry** | `8px` buttons/inputs, `12px–16px` cards, `20px` dialogs | `32px–48px` inflatable bubbles, 0px raw DOS boxes |
| **Headings** | Category eyebrow tag + bold H2 (28px–36px) + concise summary | Lines with section numbers `05 / ЛОКАЦИЯ`, GPS coords |
| **Typography** | Clean Sans-serif for UI & navigation (`14px–15px`), Monospace for prices/numbers | Monospace uppercase buttons, microscopic 8px clutter |
| **Layout** | Asymmetric bento grids, interactive widgets, generous whitespace (60–90px) | 6 consecutive gray data tables (SAP/Oracle style) |
| **Copywriting** | Concrete, tangible benefits with real prices and details | Corporate buzzword fluff ("unleash next-gen synergy") |
| **Interactivity** | Working tabs, filters, calculators, and accordions | Static fake divs, dead buttons |
