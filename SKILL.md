# ANTI-AI-SLOP: РУКОВОДСТВО ПО ИНЖЕНЕРНОМУ ВЕБ-ДИЗАЙНУ МИРОВОГО УРОВНЯ

Обязательная директива для проектирования и верстки веб-сайтов, лендингов, дашбордов и компонентов. Полностью исключает паттерны нейросетевого мусора (AI UI Slop) и переводит генерацию интерфейсов на уровень Apple, Google DeepMind, Cloudflare, GitHub, Linear, Vercel, Teenage Engineering и Stripe.

---

## 0. BRIEF INFERENCE (ЧТЕНИЕ КОНТЕКСТА ДО НАЧАЛА ВЕРСТКИ)

Главная причина плохого дизайна нейросетей — автоматический прыжок к дефолтному шаблону вместо глубокого анализа задачи. Перед написанием любой строки кода выявите сигналы:
1. **Тип продукта**: SaaS-платформа, Developer Tools, аппаратный гаджет, научный whitepaper, премиальный потребительский продукт, портфолио, B2B-инфраструктура.
2. **Аудитория**: Технические инженеры (требуют терминал, код, метрики P95) vs. C-level / инвесторы (редакционная строгость, бизнес-метрики) vs. консьюмеры (масштаб, физичность материалов).
3. **Декларация "Design Read"**: Выведите одну строку:
   `Design Read: <тип продукта> для <аудитории>, архетип <архетип>, dials: V=<1-10> / M=<1-10> / D=<1-10>.`

---

## 1. СИСТЕМА ТРЕХ РЕГУЛЯТОРОВ (THE THREE DIALS)

Все решения по геометрии, движению и плотности информации калибруются тремя шкалами (от 1 до 10):
- **DESIGN_VARIANCE (V)**: 1 = абсолютная монотонность/симметрия, 10 = асимметричный арт-хаос. (Базово: 7-8).
- **MOTION_INTENSITY (M)**: 1 = статичный макет, 10 = кинематографическая физика. (Базово: 5-6).
- **VISUAL_DENSITY (D)**: 1 = воздушная галерея (Apple), 10 = приборная панель самолета (Cloudflare/Grafana). (Базово: 4-6).

## 2. THE ABSOLUTE BAN LIST (10 ЗАПРЕТОВ СЛОПА)

Нарушение любого из этих пунктов является браком и немедленно бракуется:
1. **Запрещены градиентные радужные заголовки** (`bg-clip-text text-transparent` от розового к фиолетовому). Заголовок сплошной и контрастный (`#ffffff`, `#f5f5f7` или `#111215`). Допустим только вертикальный спад прозрачности на 15-20%.
2. **Запрещены размытые неоновые шары (Blurred Glow Orbs)** (`filter: blur(100px)`). Форма задается 1px разделителями и радиальными масками, а не цветной грязью.
3. **Запрещен шаблон "3 одинаковые карточки фич"** с иконкой по центру. Использовать асимметричные Bento-сетки (2:1, 1:2, 3:1) с разнородными артефактами.
4. **Запрещен синтетический булшит-копирайтинг** ("Supercharge", "Seamless synergy", "Next-gen", "Revolutionize"). Только конкретные глаголы, протоколы, латентности и архитектура.
5. **Запрещены декоративные эмодзи** (🚀, 🔥, 💡, ⚡) в заголовках, плашках и карточках. Использовать строгие текстовые бейджи или выверенные SVG-глифы.
6. **Запрещен голый Inter без компенсаций**. Отрицательный трекинг (`-0.02em...-0.035em`) на крупных кеглях обязателен.
7. **Запрещен прыжок карточек на ховере** (`translateY(-10px)`). Карточки стабильны, меняется только цвет границы и подложки.
8. **Запрещен бежево-латунный дефолт** (`#f7f5f1` + `#b08947` + `#1a1714`) для любых потребительских сайтов.
9. **Запрещены медленные fade-in анимации** (800ms+), блокирующие восприятие. Переходы длятся 120-220ms.
10. **Запрещены плейсхолдеры вместо label** в формах и неконтрастный текст кнопок (белый на белом).

## 4. ПОШАГОВЫЙ ПРОТОКОЛ ВЕРСТКИ

### ШАГ 1: ФИКСАЦИЯ АРХЕТИПА И ДИАЛОВ
Зафиксируйте атрибут на контейнере: `<section data-archetype="linear" class="theme-linear">`.

### ШАГ 2: ВЕРТИКАЛЬНАЯ ГЕОМЕТРИЯ И VIEWPORT
- **Hero-секция обязана помещаться в первый экран** (`min-h-[100dvh]`).
- Заголовок H1 — максимум 2 строки на десктопе (`clamp(2.5rem, 5vw, 4.5rem)`).
- Подзаголовок — максимум 20 слов, строго `max-w-[65ch]`.
- Верхний отступ не более `pt-24` (6rem), чтобы контент не проваливался вниз экрана.
- Главные кнопки CTA обязаны быть видны без скролла.

### ШАГ 3: МАТЕМАТИКА ПОВЕРХНОСТЕЙ И СВЕТА (ELEVATION)
- Используйте физические непрозрачные токены поверхностей: Canvas -> Surface-0 -> Surface-1 -> Surface-2.
- Разделители строго `1px solid rgba(255, 255, 255, 0.08)`.
- Двухкомпонентная физическая тень: `box-shadow: 0 1px 2px rgba(0,0,0,0.35), 0 4px 12px rgba(0,0,0,0.15)`.

### ШАГ 4: СТРУКТУРИРОВАНИЕ BENTO-СЕТКИ
- Правило N элементов: сетка имеет ровно столько ячеек, сколько есть контента. Никаких пустых дыр.
- Применяйте `grid-auto-flow: dense`.
- Разнообразие: запрещено ставить более 2 одинаковых карточек подряд. Сочетайте терминал (span 2), числовую метрику (span 1), список параметров (span 1) и статусную диаграмму.

### ШАГ 5: ИНЖЕНЕРНЫЙ КОПИРАЙТИНГ И АРТЕФАКТЫ
- Вставляйте реальные куски кода с подсветкой, команды CLI (`$ npm i @core/engine`), время холодного старта в миллисекундах.
- Кнопка CTA — строго 1-2 слова, без переноса строки (`whitespace-nowrap`).
- Единство намерения: одно действие — один текст кнопки на всей странице.

## 5. ПРЕ-ФЛАЙТ КОНТРОЛЬ: 15-ПУНКТОВЫЙ QUALITY GATE

Перед выдачей любого макета проверьте 15 критериев. При наличии хотя бы одной ошибки код бракуется:

1. [ ] Заголовки сплошные, без фиолетово-розовых градиентов `bg-clip-text`?
2. [ ] Отсутствуют размытые неоновые круги (`blur-[100px]`)?
3. [ ] Сетка фич асимметрична и функциональна (не 3 одинаковые плашки с иконками)?
4. [ ] Копирайтинг предметный, без слов "Supercharge", "Seamless", "Next-gen"?
5. [ ] В разметке нет декоративных эмодзи (ракет, огоньков, лампочек)?
6. [ ] Выбран ровно один архетип из 8 утвержденных?
7. [ ] Задан отрицательный трекинг (`-0.02em`...`-0.035em`) для заголовков от 32px?
8. [ ] Длина строки абзацев ограничена (`max-w-[65ch]`)?
9. [ ] Границы тонкие и физичные (1px hairline)?
10. [ ] Присутствуют реальные артефакты (терминал, таблица, график, kbd-хоткеи)?
11. [ ] Hero полностью помещается в `100dvh` и CTA виден без скролла?
12. [ ] Текст на кнопках проходит тест контрастности WCAG AA (минимум 4.5:1)?
13. [ ] Текст кнопок не переносится на вторую строку на десктопе (`whitespace-nowrap`)?
14. [ ] Поля ввода снабжены постоянными тегами `<label>`?
15. [ ] Анимации длятся 120-250ms и используют только `transform` и `opacity`?
