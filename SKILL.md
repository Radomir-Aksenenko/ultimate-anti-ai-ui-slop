# Anti-AI UI Slop & Kinetic Taste Framework

Инженерный и визуальный фреймворк для проектирования веб-интерфейсов, посадочных страниц и дизайн-систем. Сочетает строгую борьбу с шаблонностью (AI Slop 1-го и 2-го порядка) с передовой кинетической культурой, оптикой поверхностей и компонентной архитектурой.

Канонический диспетчер системы:
[skills/masterpiece-taste-design/SKILL.md](skills/masterpiece-taste-design/SKILL.md)

## 1. Иерархия приоритетов при принятии решений

1. **Ограничения функциональности и доступности (Обязательный минимум):**
   - Контрастность текста по WCAG 2.1 AA (не менее 4.5:1 для обычного текста, 3:1 для крупных надписей и управляющих элементов).
   - Полноценная навигация с клавиатуры (`:focus-visible` с контрастным кольцом смещения 2px).
   - Проектные ориентиры размеров кликабельных зон (44x44px на touch-устройствах для отдельных контролов).
   - Корректная поддержка `prefers-reduced-motion` для полного отключения навязчивой анимации.
   - Обязательные требования доступности не могут отменяться субъективными стилевыми пожеланиями.
2. **Явный бриф, существующий бренд и проверенные факты:**
   - Пожелания пользователя, фирменные цвета, существующие шрифты и реальная структура данных определяют форму и содержание в рамках доступности и имеют безусловный приоритет над общими стилевыми советами.
   - Не навязывать чужую стилистику (например, темную тему или псевдо-консоли), если проект этого не требует.
3. **Рекомендации и композиционные приемы:**
   - Применяются контекстно под задачу.
   - Скругления — обычная часть интерфейса, а не признак AI-slop. Без заданной геометрии начинай с 8–12px для кнопок и полей, 12–20px для карточек; сохраняй радиусы бренда или существующего проекта. Острые углы требуют конкретного стилевого основания. Прямоугольная сетка не обязывает делать кнопки квадратными.

## 2. Устранение AI-шаблонности первого и второго порядка

Истинная борьба с шаблонностью заключается не в замене одного набора клише другим, а в отказе от универсальных догм:

| Шаблонность 1-го порядка (Ранний AI-slop) | Шаблонность 2-го порядка (Догматический анти-слоп) | Зрелое проектное решение |
|---|---|---|
| Размытые неоновые фиолетовые сферы | Обязательный темный tech-стиль на всех сайтах | Цвет и фон определяются брендом и задачей проекта |
| 3 одинаковые карточки фич с иконками | Всегда асимметричная bento-сетка 7:5 и запрет таблиц | Формат отображения выбирается под тип данных: таблицы для плотных реестров, карточки для витрин |
| Водянистый маркетинг («Supercharge workflow») | Фейковая телеметрия («LATENCY 12ms», «99.998% uptime») | Честный предметный язык без выдуманных цифр и статусов |
| Любая гарнитура без настройки | Запрет использовать один шрифт, навязывание вычурных пар | Допустим один качественный гротеск или выверенная шрифтовая пара |
| Бесконечный анимационный шум без повода | Полный запрет на плавное движение и интерактивность | Выверенная кинетическая физика: стандартизированные кривые Безье, пружинный отклик, reduced-motion |
| Полное игнорирование структуры | Насильственный сдвиг слоев («overlap -mt-12») в каждом блоке | Естественная пространственная иерархия без искусственных наложений |
| Стерильный холодный Tailwind (Slate/Sky) | Навязанная темная тема с переключателем Sun/Moon везде подряд | Тактильная физическая палитра: теплая бумага (`#f7f7f2`), графит (`#20251f`), акцентный ультрамарин (`#2448ed`) |
| Раздувание лендинга в сухой дашборд на 20 файлов | Разрыв страницы на изолированные вкладки через React-стейт | Сфокусированное полотно лендинга с плавным скроллом и контекстными WAI-ARIA модалками |
| Попугайничанье формулировок скилла в комментариях (`Anti-Slop Grid`) | Формальное объявление `*:focus-visible` без реального Focus Trap | Чистый код без мета-шума, полный жизненный цикл доступности (Esc, Tab-trap, `body.overflow: hidden`) |

## 3. Кинетическая система и физика движения

Движение в интерфейсе решает прикладные задачи: подтверждает физический отклик на действия, обеспечивает плавность восприятия контекста и направляет внимание без задержки пользовательского потока.

### 3.1 Стандартизированные кривые ускорения (Easing Curves)

| Название кривой | Значение Cubic Bezier | Типовое применение |
|---|---|---|
| **Smooth Decel (Apple / Framer)** | `cubic-bezier(0.16, 1, 0.3, 1)` | Быстрый вход элементов, открытие карточек, диалогов, выпадающих списков. Мгновенный разгон и плавное бесшовное торможение. |
| **Natural Quintic** | `cubic-bezier(0.22, 1, 0.36, 1)` | Смена экранов, полноэкранные переходы, шторки (drawers), аккордеоны. |
| **Continuous Loop** | `cubic-bezier(0.25, 0.1, 0.25, 1)` | Бесконечные циклы: бегущие строки (marquee), медленное вращение орбит. |
| **Theatrical Reveal** | `cubic-bezier(0.65, 0, 0.35, 1)` | Акцентное раскрытие ключевых экранов или витрин. |

### 3.2 Физика пружин (Spring Dynamics для Framer Motion / Motion One)

Вместо искусственных линейных длительностей для интерактивных элементов применяется физика пружин:
- **Микро-отклик кнопок и hover:** `{ stiffness: 400, damping: 30, mass: 0.8 }`. Дает четкий упругий отклик без ощущения вязкости и без лишних колебаний.
- **Сдвиг карточек и модальные окна:** `{ stiffness: 260, damping: 28, mass: 1.0 }`. Уравновешенное движение с контролируемым импульсом.

### 3.3 Каскадное появление (Stagger Orchestration)
- Шаг задержки между соседними элементами (`staggerChildren`): **0.06–0.10s**.
- Предел каскада: не более 6 элементов. При большем объеме список анимируется единым блоком, чтобы не превращать загрузку страницы в ожидание.

### 3.4 Обязательный Reduced-Motion Fallback

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
    transform: none !important;
  }
}
```

## 4. Оптика поверхностей: Архитектура Liquid Glass

Матовое стекло придает интерфейсу осязаемую глубину, отделяя интерактивные слои от подложки без применения тяжелых глухих плашек.

### 4.1 Физическая модель многослойного стекла
1. **Полупрозрачная основа:** низкая непрозрачность базового тона (`0.04–0.08` в темной теме, `0.02–0.05` в светлой).
2. **Размытие с компенсацией сатурации:** `backdrop-filter: blur(20px) saturate(140%)`. Повышение насыщенности (`saturate(140%)`) компенсирует обесцвечивание от размытия, предотвращая появление грязного серого налета.
3. **Спекулярная фаска и контур:**
   - Внутренний блик сверху: `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.08)`.
   - Тончайший контрастный контур: `border: 1px solid rgba(255, 255, 255, 0.10)`.
   - Мягкая тень рассеивания: `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.25)`.

```css
/* Базовое матовое стекло */
.liquid-glass {
  background: rgba(255, 255, 255, 0.05);
  border: 1px solid rgba(255, 255, 255, 0.10);
  backdrop-filter: blur(20px) saturate(140%);
  -webkit-backdrop-filter: blur(20px) saturate(140%);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.08), 0 10px 30px rgba(0, 0, 0, 0.25);
}

/* Контрастное стекло повышенной четкости */
.liquid-glass-strong {
  background: rgba(255, 255, 255, 0.09);
  border: 1px solid rgba(255, 255, 255, 0.16);
  backdrop-filter: blur(24px) saturate(150%);
  -webkit-backdrop-filter: blur(24px) saturate(150%);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.15), 0 16px 40px rgba(0, 0, 0, 0.35);
}
```

## 5. Флюидная типографика и масштабирование первого экрана

Сверхкрупные заголовки первого экрана ломаются на мобильных устройствах при использовании жестких размеров вроде `text-7xl`.

### 5.1 Формула `clamp()` для монументальных заголовков
- **Ключевой Hero-заголовок:**
  `font-size: clamp(2.5rem, 7vw, 5.5rem);`
  Гарантирует кегль 40px на экранах 375px и масштабирование до 88px на дисплеях 1440px+ без неконтролируемого разрыва слов на буквы.
- **Вторичный подзаголовок:**
  `font-size: clamp(1.25rem, 3vw, 2.25rem);`

### 5.2 Оптическая компенсация трекинга
- **Кегль > 48px:** отрицательный трекинг `letter-spacing: -0.03em` до `-0.05em`, межстрочный интервал `leading-[0.95]–leading-[1.05]`.
- **Основной текст (14–18px):** нейтральный трекинг `letter-spacing: 0` или `-0.01em`, межстрочный интервал `leading-[1.5]–leading-[1.65]`.

## 6. Каталог компонентных паттернов и рецептов

### Рецепт 1: Живой первый экран (Living Hero Section)
- **Плавающий бейдж:** компактная плашка с деликатным градиентным бордером `border border-white/10 bg-white/5` и четким текстовым статусом.
- **Заголовок:** флюидный размер через `clamp()`, плотная посадка текста.
- **Кнопка действия (CTA):** контрастная заливка с упругим откликом `active:scale-[0.98] transition-transform duration-200`.
- **Интерактивная витрина (Interactive Stage):** макет рабочего окна или панели с заголовком `.liquid-glass`, структурированными данными и реальным интерактивным состоянием.

### Рецепт 2: Адаптивная Bento-сетка с микровзаимодействиями
- **Пропорции ячеек:** 2:1 для ключевого инструмента и 1:1 для вспомогательных параметров (без навязывания жесткого 7:5).
- **Интерактивный 3D Tilt:** наведение курсора мыши отклоняет карточку не более чем на 6–8 градусов. Возврат в исходное положение за 300ms с кривой `cubic-bezier(0.16, 1, 0.3, 1)`. На мобильных устройствах tilt отключается через `@media (hover: none)`.
- **Концентрические скругления:** радиус внутренних вложенных изображений рассчитывается по формуле `R_inner = max(0, R_outer - gap)`.

### Рецепт 3: Интерактивный калькулятор / слайдер параметров
Вместо скучных статичных таблиц используется функциональный блок с расчетом:
- Ползунок (`input[type="range"]`) с кастомным бегунком и клавиатурной поддержкой.
- Мгновенный пересчет значений с анимацией числового тикера.
- Честная математика тарифов или метрик без фальшивых скидок и манипуляций.

### Рецепт 4: Бесшовный CSS Marquee (Бегущая строка)
- Две группы элементов в flex-контейнере с анимацией `translateX(calc(-100% - 2rem))` на чистом CSS.
- Пауза при наведении курсора (`hover:animation-pause`) и при фокусе с клавиатуры.
- Полное отключение бегущей строки в пользу горизонтального скролла при `prefers-reduced-motion: reduce`.

### Рецепт 5: Плавающая островная навигация (Floating Island Dock)
- Компактный плавающий бар с фиксированным положением, классом `.liquid-glass` и скруглением `rounded-full`.
- Высота 48–56px, отступы `px-4 py-2`, сохранение безопасных зон `env(safe-area-inset-top)`.
- Плавный переход индикатора активного раздела на Framer Motion `layoutId="active-pill"`.

### Рецепт 6: Двухфазная архитектура экрана (Scrollytelling Phase)
- **Фаза 1 (100svh):** фокусировка на сути предложения, заголовок, кнопка действия и интерактивный объект.
- **Фаза 2 (при скролле):** плавный подъем контентного слоя поверх первого экрана, раскрывающий витрину возможностей или реестр данных без нагромождения бесконечных пустых секций.

## 7. Эталонный Blueprint промпта для генерации интерфейсов

При постановке задач генерации кода интерфейса нейросетевым моделям (Claude, Cursor, Lovable, Bolt) используется строгий 6-блочный технический каркас:

1. **Системный контекст и стек:** явное указание версий (React 19 + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React).
2. **Цветовая палитра и точные токены:** значения Hex для фона (`#0C0C0C`), границ (`rgba(255,255,255,0.08)`), текста (`#FFFFFF` и `rgba(255,255,255,0.6)`), оптические параметры `.liquid-glass`.
3. **Типографическая спецификация:** шрифт заголовков и текста, точная формула `clamp()` для экранов, трекинг и интерлиньяж.
4. **Анатомия блоков и компоновка:** точный порядок секций (Floating Nav -> Living Hero -> Bento Stage -> Footer), соотношение колонок, плотность отступов.
5. **Кинетический профиль:** стандартизированная кривая Безье (`cubic-bezier(0.16, 1, 0.3, 1)`), параметры пружин, задержки каскада (stagger 0.08s), ховер-состояния.
6. **Доступность и эргономика:** сенсорные мишени 44x44px, `:focus-visible` контуры, поддержка `prefers-reduced-motion`.
