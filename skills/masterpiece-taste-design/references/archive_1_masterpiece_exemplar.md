# Эталонный архитектурный стандарт: Архив 1 (Концепт «Ветер»)

Канонический образец реализации посадочной страницы потребительского продукта высочайшего уровня вкуса, инженерной строгости и доступности. Служит практическим ориентиром для всех моделей при проектировании веб-интерфейсов.

## 2. Тактильная цветовая система (Warm Paper Palette)

Вместо холодного темного «крипто-минимализма» или стерильного белого цвета, интерфейс строится на теплой, тактильной материальности:

```css
:root {
  --paper: #f7f7f2;          /* Теплая органическая подложка (бумага) */
  --ink: #20251f;            /* Природный глубокий графит для ключевого текста */
  --blue: #2448ed;           /* Чистый высокоэнергетичный ультрамарин для фокуса и кнопок */
  --muted: #757970;          /* Сдержанный нейтральный тон для второстепенных меток */
  --line: #e3e5dc;           /* Костяной оттенок тонких разделителей (1px) */
  --selection: #d6deff;      /* Контрастное выделение текста */
}

/* Гарантия контраста WCAG 2.1 AA для вторичной информации на теплой бумаге */
.search-field small,
.search-options,
.trust-note,
.destination-meta,
.price-note,
.modal-subtitle {
  color: #656e5b; /* Коэффициент контраста > 4.6:1 к фону #f7f7f2 */
}
```

1. **Отрицательный трекинг крупного заголовка:**
   `font-size: clamp(52px, 5.6vw, 80px); font-weight: 500; line-height: 1.04; letter-spacing: -4.3px;`
   Плотная посадка букв исключает ощущение пустоты и разрозненности.

   Консоль поиска билетов заходит на фотокарточку снизу с `margin: -49px 23px 0`, создавая осязаемую глубину без искусственных 3D-теней.
3. **Художественный росчерк (flight-doodle):**
   Легкая штриховая SVG-линия траектории полета с маленьким самолетом в aside-блоке добавляет человечности и брендового характера.

## 4. Золотой стандарт WAI-ARIA Modal (Accessible Focus Trap)

Любые модальные окна обязаны реализовывать полный жизненный цикл доступности:

```tsx
import { useEffect, useRef, type ReactNode } from 'react';

interface ModalProps {
  title: string;
  children: ReactNode;
  onClose: () => void;
}

export function Modal({ title, children, onClose }: ModalProps) {
  const ref = useRef<HTMLDivElement>(null);
  const onCloseRef = useRef(onClose);
  onCloseRef.current = onClose;

  useEffect(() => {
    // 1. Сохраняем элемент, вызвавший открытие, для возврата фокуса
    const previousActiveElement = document.activeElement as HTMLElement;
    const originalOverflow = document.body.style.overflow;
    
    // 2. Блокируем фоновый скролл страницы
    document.body.style.overflow = 'hidden';
    
    // 3. Переводим фокус на контейнер модального окна
    ref.current?.focus();

    // 4. Циклический перехват клавиш Tab и закрытие по Escape
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
        onCloseRef.current();
        return;
      }
      if (e.key === 'Tab') {
        const focusable = ref.current?.querySelectorAll<HTMLElement>(
          'button:not([disabled]), a[href], input:not([disabled]), select:not([disabled]), [tabindex="0"]'
        );
        if (!focusable || focusable.length === 0) return;
        
        const first = focusable[0];
        const last = focusable[focusable.length - 1];

        if (e.shiftKey && (document.activeElement === first || document.activeElement === ref.current)) {
          e.preventDefault();
          last.focus();
        } else if (!e.shiftKey && document.activeElement === last) {
          e.preventDefault();
          first.focus();
        }
      }
    };

    document.addEventListener('keydown', handleKeyDown);
    
    // 5. Очистка и обязательный возврат фокуса
    return () => {
      document.body.style.overflow = originalOverflow;
      document.removeEventListener('keydown', handleKeyDown);
      previousActiveElement?.focus();
    };
  }, []);

  return (
    <div className="modal-backdrop" onClick={onClose}>
      <div 
        className="modal" 
        role="dialog" 
        aria-modal="true" 
        aria-label={title} 
        tabIndex={-1} 
        ref={ref} 
        onClick={e => e.stopPropagation()}
      >
        <div className="modal-heading">
          <h2>{title}</h2>
          <button className="icon-btn" onClick={onClose} aria-label="Закрыть">
            <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="1.6">
              <path d="m6 6 12 12M6 18 18 6" />
            </svg>
          </button>
        </div>
        {children}
      </div>
    </div>
  );
}
```

## 5. Мобильная эргономика: Тач-таргеты 44x44px

На экранах смартфонов и планшетов (`max-width: 760px`) все управляющие кнопки, иконки, стрелки и счетчики должны гарантировать размер зоны нажатия не менее 44x44px:

```css
@media (max-width: 760px) {
  /* Круглые и квадратные кнопки управления */
  .icon-btn,
  .slide-controls > button,
  .counter button {
    width: 44px;
    height: 44px;
  }

  /* Скрытая невидимая зона касания для компактных кнопок */
  .swap-btn:before {
    content: '';
    position: absolute;
    width: 44px;
    height: 44px;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
  }

  /* Табы и ссылки в меню */
  .filter-tabs button,
  .footer-links button,
  .footer-links a,
  .main-nav.is-open a,
  .main-nav.is-open > button {
    min-height: 44px;
    display: flex;
    align-items: center;
  }
}
```

## 6. Честная интерактивность [Demo]

Когда создается прототип или концепт:
1. **Никаких выдуманных реквизитов без маркировки:**
   - Вместо фейкового телефона 8-800 — четкое указание каналов связи или пометка `[Demo] Концепт авиакомпании`.
   - В футере обязательна строгая строка: `[Demo] Концепт авиакомпании. Реальные билеты не продаются.`
2. **Предустановленные демо-коды для мгновенного тестирования:**
   - В поле «Номер рейса» подсказка: *«Например, ВТ 204»*.
   - В поле «Код бронирования» подсказка: *«Например, VETER1»*.
   - При вводе этих кодов система сразу отображает демонстрационную бронь или статус рейса, позволяя пользователю увидеть законченный сценарий.
