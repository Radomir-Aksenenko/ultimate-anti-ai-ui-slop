# Кинетический дизайн, оптика поверхностей и микро-взаимодействия

Руководство по интеграции выверенной физики движения, полупрозрачных оптических поверхностей, флюидной типографики и интерактивных компонентов.

---

## 1. Кинетическая дисциплина и борьба с анимационным шумом

Анимация в интерфейсе решает прикладные задачи: подтверждает физический отклик на действие пользователя, сохраняет контекст при переключении состояний и направляет визуальное внимание.

### Принципы зрелого движения
1. **Функциональность превыше зрелищности:** движение не должно задерживать пользователя в решении задачи. Любая анимация взаимодействия должна укладываться в интервал 150–350 мс.
2. **Отсутствие бесконечного фонового шума:** запрещено нагромождать постоянные фоновые покачивания, пульсирующие цветные ореолы и блуждающие градиенты, отвлекающие от чтения информации.
3. **Безусловное подчинение доступности:** любая кинетическая механика обязана иметь альтернативный статичный или мгновенный сценарий при системном запросе `prefers-reduced-motion: reduce`.

## 2. Физика движения и стандартизированные кривые ускорения

Естественность движения определяется математической кривой Безье (cubic-bezier) и физикой пружин (spring physics).

### 2.1 Стандартизированная таблица кривых ускорения

| Имя кривой | Значение Cubic Bezier | Применение |
|---|---|---|
| **Smooth Decel (Apple/Framer)** | `cubic-bezier(0.16, 1, 0.3, 1)` | Быстрый вход элементов, открытие модальных окон, карточек и выпадающих списков. Быстрый разгон и мягкое, бесшовное торможение. |
| **Natural Quintic** | `cubic-bezier(0.22, 1, 0.36, 1)` | Полноэкранные переходы, выдвижные боковые панели (drawers), аккордеоны. |
| **Continuous Loop** | `cubic-bezier(0.25, 0.1, 0.25, 1)` | Бесконечные циклы: бегущие строки (marquee), медленное вращение орбит, непрерывный скролл. |
| **Theatrical Reveal** | `cubic-bezier(0.65, 0, 0.35, 1)` | Драматическое раскрытие ключевых экранов и карточек-витрин с акцентированным замедлением в центре фазы. |

### 2.2 Параметры пружинной динамики (Spring Dynamics)

Для интерфейсов на Framer Motion / Motion One рекомендуется использовать физические параметры пружин вместо искусственных линейных длительностей:

- **Микро-отклик кнопок и hover-эффекты:**
  `transition: { type: "spring", stiffness: 400, damping: 30, mass: 0.8 }`
  Обеспечивает мгновенную тактильную отдачу без ощущения вязкости и без лишних колебаний.
- **Раскрытие карточек и сдвиг слоев:**
  `transition: { type: "spring", stiffness: 260, damping: 28, mass: 1.0 }`
  Уравновешенное движение с контролируемым импульсом.

### 2.3 Каскадное появление (Stagger Orchestration)

При выводе списков карточек, пунктов меню или параметров:
- Шаг задержки между соседними элементами (`staggerChildren`): **0.06–0.10s**.
- Предел каскада: не более 6 элементов. При большем объеме данных анимируется контейнер целиком либо элементы группируются блоками, чтобы не превращать загрузку в ожидание.

### 2.4 Обязательный Reduced-Motion Fallback

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

В коде Framer Motion:
```tsx
import { useReducedMotion } from "framer-motion";

const shouldReduceMotion = useReducedMotion();
const transition = shouldReduceMotion
  ? { duration: 0 }
  : { duration: 0.3, ease: [0.16, 1, 0.3, 1] };
```

## 3. Оптика поверхностей: архитектура Liquid Glass

Эффект матового стекла (`liquid-glass`) придает интерфейсу объем и тактильную глубину, разделяя уровни информации без использования тяжелых глухих фонов.

### 3.1 Физическая модель слоев

Стекло строится из трех взаимосвязанных физических компонентов:
1. **Полупрозрачная подложка:** низкая непрозрачность базового тона (`0.04–0.08` в темной теме, `0.02–0.05` в светлой).
2. **Размытие с компенсацией насыщенности:** `backdrop-filter: blur(16px) saturate(140%)`. Сатурация (`saturate`) критически важна: она возвращает цветность, которая вымывается оптическим размытием, предотвращая эффект грязного серого пятна.
3. **Спекулярная фаска и контур:**
   - Внутренний светящийся блик сверху: `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.10)`.
   - Тончайшая контрастная граница: `border: 1px solid rgba(255, 255, 255, 0.08)`.
   - Мягкая внешняя тень рассеивания: `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.25)`.

### 3.2 Готовые CSS-классы поверхностей

```css
/* Базовое полупрозрачное стекло */
.liquid-glass {
  background: rgba(255, 255, 255, 0.05);
  border: 1px solid rgba(255, 255, 255, 0.10);
  backdrop-filter: blur(20px) saturate(140%);
  -webkit-backdrop-filter: blur(20px) saturate(140%);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.08), 0 10px 30px rgba(0, 0, 0, 0.25);
}

/* Контрастное стекло повышенной четкости */
.liquid-glass-strong {
  background: rgba(255, 255, 255, 0.09);
  border: 1px solid rgba(255, 255, 255, 0.16);
  backdrop-filter: blur(24px) saturate(150%);
  -webkit-backdrop-filter: blur(24px) saturate(150%);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.15), 0 16px 40px rgba(0, 0, 0, 0.35);
}

/* Светлая тема */
[data-theme="light"] .liquid-glass {
  background: rgba(255, 255, 255, 0.65);
  border: 1px solid rgba(0, 0, 0, 0.08);
  backdrop-filter: blur(20px) saturate(120%);
  -webkit-backdrop-filter: blur(20px) saturate(120%);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.8), 0 8px 24px rgba(0, 0, 0, 0.06);
}
```

## 4. Флюидная типографика и масштабирование экранов

Монументальные заголовки первых экранов часто ломаются на планшетах и смартфонах при использовании жестких размеров (`text-7xl`).

### 4.1 Формула адаптивного масштабирования `clamp()`

Вместо фиксированных шагов брейкпоинтов используется функция `clamp()` с относительными единицами ширины окна (`vw`):
- **Монументальный Hero-заголовок:**
  `font-size: clamp(2.5rem, 7vw, 6rem);`
  Гарантирует, что на экране шириной 375px заголовок не превысит 40px, а на экранах 1440px+ развернется до 96px без переносов отдельных букв.
- **Вторичный подзаголовок раздела:**
  `font-size: clamp(1.5rem, 3.5vw, 2.75rem);`

### 4.2 Дисциплина межбуквенного и межстрочного интервала

Для сверхкрупных дисплейных надписей действуют правила оптической компенсации:
- **Кегль > 48px:** отрицательный трекинг `letter-spacing: -0.03em` до `-0.05em`. Межстрочный интервал `line-height: 0.95–1.05`.
- **Основной текст (14–18px):** нейтральный трекинг `letter-spacing: 0` или `-0.01em`. Межстрочный интервал `line-height: 1.5–1.65`.

### 4.3 Шрифтовые комбинации

- **Техничный монументальный контраст:** дисплейный акцент (Kanit, Syne, Clash Display) для заголовков + нейтральный гротеск (Inter, Geist, Manrope) для данных.
- **Швейцарская нейтральная строгость:** один качественный гротеск (Inter / Geist / Helvetica Neue) с дифференциацией исключительно через размер и плотность начертания (font-weight: 400, 500, 700).

## 5. Интерактивные паттерны и компоненты

### 5.1 Бесшовный бесконечный Marquee (Чистый CSS)

Реализация бегущей строки логотипов или тегов без использования JavaScript-таймеров:

```html
<div class="marquee-wrapper overflow-hidden select-none">
  <div class="marquee-track flex gap-8 whitespace-nowrap">
    <div class="marquee-group flex gap-8 items-center shrink-0">
      <!-- Элементы строки -->
    </div>
    <div class="marquee-group flex gap-8 items-center shrink-0" aria-hidden="true">
      <!-- Точная копия элементов для непрерывности цикла -->
    </div>
  </div>
</div>
```

```css
.marquee-track {
  animation: marquee-scroll 28s linear infinite;
}

@keyframes marquee-scroll {
  from { transform: translateX(0); }
  to { transform: translateX(calc(-100% - 2rem)); }
}

@media (hover: hover) {
  .marquee-wrapper:hover .marquee-track {
    animation-play-state: paused;
  }
}

@media (prefers-reduced-motion: reduce) {
  .marquee-track {
    animation: none;
    overflow-x: auto;
  }
}
```

### 5.2 Интерактивный 3D Tilt (Наклон карточек)

Плавный отклик на положение курсора мыши над интерактивной карточкой:
- **Максимальный угол наклона:** не более 6–8 градусов по осям X/Y. Превышение этого угла ухудшает разборчивость текста и производит впечатление небрежности.
- **Плавный возврат:** при уходе курсора карточка возвращается в плоскость с кривой `cubic-bezier(0.16, 1, 0.3, 1)` за 300 мс.
- На мобильных touch-устройствах эффект наклона полностью отключается через `@media (hover: none)`.

### 5.3 Интерактивные калькуляторы и ползунки (Range Sliders)

Вместо статичных прайс-таблиц современные конверсионные интерфейсы используют интерактивный расчет параметров:
- Отображение текущего значения в реальном времени с плавным числовым тикером.
- Кастомный трек и бегунок слайдера (`appearance: none`, `accent-color` либо стилизованный thumb 20x20px).
- Синхронизация с клавиатурой: поддержка клавиш со стрелками, `Home`, `End` с шагом (`step`).

### 5.4 Радиальные и орбитальные структуры данных

Используются для наглядного представления связей вокруг центрального ядра системы:
- Расчет координат меток производится через угол и радиус:
  `x = center_x + radius * cos(angle)`
  `y = center_y + radius * sin(angle)`
- Метки сохраняют горизонтальную ориентацию текста независимо от угла орбиты для поддержания читаемости.

## 6. Архитектура эталонного UI-промпта (Prompt Blueprint)

При формулировании задач генерации кода интерфейса моделям (Claude, Lovable, Bolt, Cursor) исключается субъективная вода. Используется строгий 6-блочный технический каркас:

1. **Системный контекст и стек:** точные версии библиотек (например, React 19 + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React).
2. **Цветовая палитра и точные токены:** значения Hex для фона, границы, основного и приглушенного текста, правила для стекол и акцентов.
3. **Типографическая спецификация:** семейство шрифтов, способ подключения (Google Fonts / local), правила `clamp()` для заголовков, трекинг и интерлиньяж.
4. **Анатомия секций и компоновка:** точная последовательность блоков, пропорции сеток (Bento 2:1 или 1:1, таблицы данных, шапка, подвал).
5. **Кинетический профиль:** конкретные кривые Безье, длительности переходов, пружинные параметры, каскадные задержки и поведение hover.
6. **Доступность и эргономика:** правила `:focus-visible`, сенсорные зоны 44x44px, отключение движения при `prefers-reduced-motion`.
