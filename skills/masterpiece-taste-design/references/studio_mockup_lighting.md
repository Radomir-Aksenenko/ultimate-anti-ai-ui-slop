# Студийное освещение и физика теней в презентационных сценах

Контекстное руководство по работе со студийным светом, тенями и текстурами в мокапах и презентационных материалах.
Приведенные формулы являются примерами для графической визуализации и мокапов, а не обязательной эстетикой для обычных компонентов веб-интерфейса.

---

## 1. Приемы распределения теней в мокапах

В графических презентациях и рендерах физическое ощущение глубины достигается разделением тени на компоненты:

### 1.1 Пример многослойной тени (CSS / Рендеринг)
```css
.studio-mockup-shadow {
  box-shadow:
    /* Контактная тень: плотная окклюзия непосредственно под объектом */
    0 2px 4px rgba(0, 0, 0, 0.08),
    /* Направленная тень: смещение по лучу основного источника */
    0 8px 16px rgba(0, 0, 0, 0.06),
    /* Рассеянная тень: мягкое фоновое рассеяние */
    0 24px 48px -8px rgba(0, 0, 0, 0.05);
}
```

### 1.2 Темные фоны и контраст
На темных подложках тени низкой прозрачности теряют читаемость. В таких сценах объем передается не раздуванием тени, а:
- Тонким контуром (`border: 1px solid rgba(255, 255, 255, 0.08)`);
- Легким перепадом яркости между поверхностью карточки и холстом;
- Деликатным световым акцентом на верхней грани.

---

## 2. Текстурные ориентиры для графики

- **Матовые и бумажные поверхности:** для упаковок и полиграфических мокапов допустима деликатная растровая текстура или легкий шум (1–2%), снимающий ощущение синтетического пластика.
- **Стекло и прозрачные материалы:** умеренное размытие фона (`backdrop-filter`) и аккуратная светлая кайма на ребре.
- **Металлические корпуса:** направленные отражения вдоль фасок устройства.
