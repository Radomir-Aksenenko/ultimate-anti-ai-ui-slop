# Sub-Skill: Студийные мокапы и растровые материалы

Руководство по созданию фотореалистичных подач дизайн-макетов в Photoshop и растровых редакторах.

---

## 1. Трехуровневая модель слоев мокапа

Для корректной физической интеграции макета в сцену используется трехслойная структура:

`
[Слой 3 - Верхний]  Блики и спекулярные отражения (Screen / Осветление, непрозрачность 15–30%)
[Слой 2 - Средний]  Смарт-объект с макетом (Multiply для бумаги/ткани; Normal 90–100% для экранов)
[Слой 1 - Базовый]  Физическая поверхность сцены (бумага, бетон, дерево, металл корпуса)
`

### 1.1 Базовый слой (Основа)
- Реалистичная текстура материала с естественным микро-рельефом.
- Нейтральный баланс белого, позволяющий дизайну оставаться читаемым.

### 1.2 Слой макета (Смарт-объект)
- Неразрушающее редактирование через Smart Object.
- Режим **Multiply (Умножение)** используется для полиграфии, постеров, упаковки и ткани, чтобы фактура основы органично просвечивала сквозь печать.
- Режим **Normal** с легким спадом непрозрачности (95–100%) используется для экранов устройств (OLED, Retina).

### 1.3 Слой освещения и бликов
- Режим **Screen (Осветление)** имитирует направленный софтбокс или естественный свет из окна.
- Непрозрачность калибруется в диапазоне 15–30%, чтобы не размывать контрастность самого макета.

## 2. Естественные тени контакта

- Контактная тень (Ambient Occlusion): узкая, насыщенная, с малым радиусом размытия непосредственно под объектом.
- Рассеянная тень: мягкая, широкая тень по направлению источника света.
